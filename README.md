# Codelabs | Kartik Arora

Interactive step-by-step technical tutorials and workshops for modern technologies, built with the **@kartikarora Brand Design System** and **Klaat**.

Hosted on Cloudflare Pages at [codelabs.kartikarora.me](https://codelabs.kartikarora.me) (or [kartikarora.me/codelabs](https://kartikarora.me/codelabs)).

---

## 🛠️ Architecture & Tech Stack

- **Design System**: [@kartikarora Brand Design System](https://distribute.kartikarora.me/css/kartikarora.css) (Fluid typography, Albert Sans & JetBrains Mono, dynamic system themes, CLS prevention).
- **Codelab Compiler**: **Klaat** (`klaat-snapshot` / `klaat`) — High-performance markdown to interactive HTML codelab exporter.
- **Manifest & Build System**: Node.js (`generate-manifest.js`) generates `dist/codelabs.json` and prepares the static site output.
- **Deployment Platform**: Cloudflare Pages / Wrangler (`wrangler.toml`).

## 🚀 Development Workflow

### 1. Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [Klaat](https://github.com/kartikarora/klaat) (Install via Homebrew):
  ```bash
  brew tap kartikarora/klaat
  brew install klaat
  ```
  Or the snapshot release:
  ```bash
  brew tap kartikarora/klaat-snapshots
  brew install klaat-snapshot
  ```

### 2. Authoring a Codelab

1. Create a subdirectory under `source/<slug>/`.
2. Add your tutorial content in `codelab.md` with valid YAML frontmatter following the `klaat-markdown-author` specification:
   ```markdown
   ---
   id: my-awesome-codelab
   summary: A short single-sentence summary of the codelab.
   categories: AI, Android, Web
   environments: Web
   status: Published
   authors: Kartik Arora
   feedback_link: https://kartikarora.me
   tags: ai, kotlin, web
   ---

   # Title of Codelab

   ## Step 1
   Duration: 5

   Content for step 1...
   ```
3. Place local images in `source/<slug>/images/` and reference them as `images/<filename>`.

### 3. Exporting Codelabs

Compile the Markdown source into interactive HTML codelabs using `klaat`:

```bash
klaat-snapshot export -o codelabs source/my-awesome-codelab/codelab.md
```

### 4. Building the Distribution Manifest

Generate `dist/` and build the dynamic `codelabs.json` index:

```bash
node generate-manifest.js
```

### 5. Local Preview

Start a local web server pointing to the `dist` directory:

```bash
# Using Python 3
python3 -m http.server 8000 --directory dist

# OR using Wrangler
npx wrangler dev
```

Visit [http://localhost:8000](http://localhost:8000) in your browser.
